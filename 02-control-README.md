# Control Flow in Python

This folder contains Python programs and exercises focused on **control flow statements**. These concepts are essential for controlling the execution and decision-making process of a Python program.

## 📚 Topics Covered

- Conditional Statements
- `if` Statement
- `if-else` Statement
- `if-elif-else` Statement
- Nested `if` Statements
- `for` Loop
- `while` Loop
- Nested Loops
- `break` Statement
- `continue` Statement
- `pass` Statement
- Range Function
- Basic Problem Solving Using Control Flow

## 💻 Practice Programs

The programs in this folder include exercises such as:

- Check whether a number is positive, negative, or zero
- Check whether a number is even or odd
- Find the largest of two or three numbers
- Check whether a year is a leap year
- Check whether a number is prime
- Print numbers using loops
- Calculate the sum of numbers
- Generate multiplication tables
- Generate Fibonacci series
- Calculate factorial of a number
- Use `break` and `continue` statements
- Solve problems using nested loops
